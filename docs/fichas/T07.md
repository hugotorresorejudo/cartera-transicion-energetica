# T07 — Cargador doméstico y potencia contratada

## 1. Objetivo y decisión

Elegir la potencia del punto de recarga (3,7, 7,4 o 11 kW), si instalar gestión dinámica de potencia y qué potencia contratar, minimizando el coste de potencia con una probabilidad de corte admitida.

## 6. Método de cálculo con ecuaciones LaTeX

Tiempo de carga y comprobación de la ventana:

```latex
t_{ch}=\frac{E_d}{P_{ch}},\qquad \Pr(t_{ch}\le T_{disp})\ge \gamma
```

Potencia requerida por muestra (P_max de simultaneidad con o sin el VE) y recomendada por cuantil, sobre las potencias normalizadas 𝒫:

```latex
P^{req}_i=\min\{P\in\mathcal{P}: P\ge P^{max}_i\},\qquad P^*=Q_{1-\alpha}\big(P^{req}\big)
```

```latex
P^{max,gest}=\max\big(P^{max}_{otros},\ P_{ch}+P_{base}\big)
```

Coste extra de potencia frente a la actual:

```latex
\Delta C=\big(P^*-P_{act}\big)^+\,\frac{\pi_1+\pi_2}{2}\,(1+\tau_{IEE})(1+\tau_{IVA})
```

## 8. Validación y limitaciones

- **Validación:** la configuración recomendada nunca supera el máximo monofásico si el suministro lo es; más potencia de cargador no reduce las horas de carga.
- **Limitación:** la gestión dinámica se modela de forma simplificada (el VE solo coincide con la base nocturna).
- **Limitación:** no se incluyen el coste de adaptar el suministro a trifásico ni los trámites de comunidad.
- **Limitación:** la simultaneidad usa probabilidades de uso supuestas, no medidas.
