# T05 — Bomba de calor para ACS vs termo eléctrico / calentador

## 1. Objetivo y decisión

Ayuda a elegir el sistema de ACS: termo eléctrico, calentador o caldera de gas, o bomba de calor para ACS. Cuantifica el coste anual, el VAN del cambio y las emisiones.

## 6. Método de cálculo con ecuaciones LaTeX

Volumen de uso y volumen equivalente a la temperatura de acumulación:

```latex
V_{uso}=n\,(d\,t\,q)+V_{ba\tilde{n}}+V_{otros},\qquad V_{ac}=V_{uso}\,\frac{T_{uso}-T_{red}}{T_{ac}-T_{red}}
```

Energía útil y pérdidas, con ρc_p = 1,163 Wh/(L·K):

```latex
Q_d=\rho c_p\,V_{uso}\,(T_{uso}-T_{red}),\qquad Q_{loss,t}=UA\,(T_{ac}-T_{amb,t})\,\Delta t
```

Consumo según el sistema (gas en base PCS):

```latex
E^{termo}=\sum_t (Q_t+Q_{loss,t})
```

```latex
F^{gas}=\sum_t\frac{Q_t+Q_{loss,t}}{\eta_g}
```

```latex
E^{BdC}=\sum_t\frac{Q_t+Q_{loss,t}}{COP(T_{aire,t},T_{ac})}+E^{apoyo}_t
```

Modelo del COP: interpolación de los puntos del fabricante o, si no existen, la expresión siguiente [η_C: verificar]. El apoyo eléctrico entra cuando T_aire < T_min,BdC.

```latex
COP=\eta_C\,\frac{T_h}{T_h-T_c}
```

Programación: calentar en las horas de menor precio o con FV, con el depósito como restricción de capacidad (LP análogo a T04). Coste con T01 y T22; VAN, TIR y payback del cambio con el módulo financiero común.

## 7. Salidas con rango P10–P90

- Litros/día equivalentes a 60 °C (rango), contrastados con la referencia CTE.
- Energía útil (kWh/año).
- Coste anual por sistema (P10 / P50 / P90).
- VAN, TIR y payback del cambio.
- CO₂ anual por sistema.

## 8. Validación y limitaciones

- **Validación 1:** contraste de V_ac con la referencia CTE.
- **Validación 2:** con caldera mixta o calentador, el consumo de gas en verano (factura) aproxima ACS + cocina.
- **Limitación:** fuerte componente de comportamiento.
- **Limitación:** el COP real depende del patrón de extracción.
- **Limitación:** no se modelan recirculación ni pérdidas de distribución.
- **Limitación:** los ciclos antilegionela aumentan el consumo.
- **Limitación:** el espacio y el ruido de la bomba de calor no se evalúan.
